# Playovia Worlds — Godot 4

Native game source authored in GDScript and Godot scenes. HTML is generated by Godot's browser export only; gameplay is not hand-written in HTML.

Current first playable: Street Racer with 3D chase camera, city skyline, traffic, score, speed, lives and touch/keyboard input. Renderer uses Godot Compatibility mode for WebGL/mobile.

Open this folder in Godot 4.4+. Public asset sourcing plan is in ASSET_SOURCES.md. Next art pass imports Kenney CC0 vehicle/city GLB models; Adventure and Arena will be separate native Godot scenes.
